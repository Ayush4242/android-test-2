This Jetpack Compose Android application implements a reactive e-commerce product search feature. The MainActivity hosts the main SearchScreen, which includes an interactive text field and a scrollable LazyColumn to display results. Powered by a SearchViewModel, the app tracks user queries using Kotlin StateFlows and applies a 500ms debounce to optimize typing performance. Upon entering a query, it triggers a simulated asynchronous network fetch on an IO dispatcher, temporarily showing a loading indicator before displaying mock product suggestions
